# QA 체크리스트

자동 테스트가 전부 통과해도 **사람이 눌러야만 나오는 결함**이 있다: 겹침·잘림·빈 상태·느린 연출·지도 위 위치.

## 항목을 뽑는 기준

변경한 파일에서 역산한다. **바꾸지 않은 화면은 넣지 않는다** — 목록이 길면 안 누른다.

| 변경 종류 | 뽑을 것 |
| --- | --- |
| 화면 부품·CSS | 넓은 폭 / 좁은 폭 / 긴 이름 / 빈 상태 / 위반·휴무 상태 |
| 지도 | 핀·경로가 패널에 가리지 않는가 / 범위 맞춤 / 확대·축소 |
| 연출 | 끝까지 기다림 / 중간에 클릭해서 건너뛰기 / 동작 줄이기 설정 |
| 에이전트 응답 | 응답이 늦을 때 / 실패할 때 대체 화면이 뜨는가 |
| 폼·입력 | 비우고 제출 / 지난 날짜 / 수정 화면에 기존값 |
| 환경 | **Windows(WSL) 팀원 기기에서 한 번** — 줄바꿈·경로·파일 감지 |
| 마이그레이션 | 서버 재시작 / 기존 데이터가 그대로 보이는가 |

## 출력 형식

화면 단위로 묶고, 어디서 무엇을 누르는지 순서대로 쓴다.

```
결과 화면
  [ ] 검증하기 → 경로가 구간마다 그려지는가
  [ ] 연출 중 지도를 누르면 바로 최종 화면이 되는가
  [ ] 휴무 스팟 카드에 작은 태그만 뜨는가 (카드 전체 빨강 아님)
```

## 하지 않을 것

- **Claude가 대신 눌렀다고 하지 않는다.** 스크린샷으로 확인한 것은 그렇게 말하되, 실기기·Windows·실제 API 응답은 대신할 수 없다.
- 체크를 대신 채우지 않는다.
